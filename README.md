A **secure, local AI Data Analyst** that runs on your machine. It allows you to drag-and-drop CSV files, ask questions in plain English, and instantly get Python analysis and visualization charts. 

Built with **Streamlit**, **LangGraph**, and **Google Gemini 2.0 Flash**.

---
### ⚡ The Power of the Analyst
* **🔒 Privacy First:** Your data stays on your local machine. It is never uploaded to external training servers.
* **🧠 Deep Reasoning:** Utilizes **LangGraph** to "think" before it acts—planning analysis steps and correcting its own errors.
* **🐍 Python Native:** It doesn't guess numbers; it writes **Pandas** code to calculate them precisely.
* **🤖 Autonomous Coding:** The agent writes and executes its own Python code to analyze data.
* **📊 Visualization Engine:** Automatically detects the best chart type (Heatmaps, Bar Charts, Line Graphs) and plots them using **Matplotlib**.
